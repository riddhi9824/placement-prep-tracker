# Placement Preparation Tracker

A full-stack web application that helps students organize and manage their placement preparation.

## Features

- User registration and login
- Placement application tracking
- Company and application management
- DSA preparation tracking
- Personalized dashboard
- Secure authentication
- MongoDB database integration
- RESTful APIs

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS
- Vite

### Backend
- Node.js
- Express.js

### Database
